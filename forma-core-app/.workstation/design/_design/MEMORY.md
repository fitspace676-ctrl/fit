# Design memory

## FormaCore mobile art direction — Lime Block (დამტკიცებული)

დამტკიცებული მიმართულებაა "Lime Block" (mobile-home-v2.tsx), ძველი "Night Deck" გაუქმებულია. ნახშირისფერი ტილო ink-950, შიგთავსი დიდ რბილკუთხოვან ფერად ბლოკებშია (rounded-[26px]–[32px]): ლაიმი brand-300 მხოლოდ და მხოლოდ აბონემენტის ბლოკზე, გაკვეთილები მონაცვლეობით accent-300 ლავანდი და iris-200 ვარდისფერი, ტექსტი მათზე ink-950. ბლოკის კიდეზე მოჭრილი გიგანტური მონო ციფრი (გაკვეთილის დრო) ვიზუალურ აქცენტს ქმნის — არა ფოტო, არა დეკორაცია. თეთრი მრგვალი ბეჯი ხანგრძლივობით, ღილაკები rounded-pill, ნავიგაცია მცურავი თეთრი კაფსულაა ხუთი წრიული ღილაკით, აქტიური accent-500. ფოტოები კანვასზე არ იტვირთება (stocksnap/picsum იბლოკება) — მხოლოდ i.pravatar.cc ავატარები მუშაობს.

## შიგთავსი მხოლოდ codebase-იდან

არცერთი არტბორდი არ იგონებს მონაცემს. კლასები, ტევადობა, ხანგრძლივობა და კატეგორიის ფერი — prisma/seed.ts (CLASS_TYPES, DEMO_TODAY_CLASSES); მწვრთნელები DEMO_TRAINERS (Ana G., Levan M., Sandro K., Nika B.), ლოკაციები Main Floor / Studio A, დარბაზი Downtown Strength, წევრი Nino Kapanadze / Premium; პროდუქტები DEMO_PRODUCTS-ის რეალური GEL ფასებით formatMoney-ის ფორმატში ("89,00 ₾"). ტექსტი მხოლოდ @fit/i18n ka.json-ის სიტყვასიტყვითი სტრიქონებია, სტატუსები კი BOOKED / WAITLIST / ATTENDED და ACTIVE / TRIAL / FROZEN / PAST_DUE. კატეგორიის ფერი ყოველთვის მონაცემიდან მოდის inline style-ით (ClassInstanceCard.color), არასდროს კლასის სახელით. დეკორაცია — გრადიენტის ლაქები, ყალბი ბრწყინვა — აკრძალულია.

## Moodboard vs design system

moodboard.tsx (გვერდი Foundations) არის არტ-მიმართულების დაფა — მიმართულების ერთი წინადადება, ტონის სიტყვები, პალიტრა როლებით, ტიპოგრაფიის სპეციმენი, ზედაპირის წესი, radius/elevation საფეხურები, ხელმოწერა (მოჭრილი ციფრი) და სპოტ-ილუსტრაციის ენა. design-system.tsx რჩება კომპონენტების გალერეად. ახალი ეკრანი ჯერ moodboard-ს უნდა შეესაბამებოდეს, მერე გალერეიდან იღებს კომპონენტს.

## პალიტრა: მონოქრომი + ერთი ლაიმი

პროდუქტს ერთადერთი ფერი აქვს — ლაიმი brand-300 (#E4F26A) და ის მხოლოდ აბონემენტს, მთავარ ქმედებას და დადასტურებულ ჯავშანს ეკუთვნის. accent და iris ტოკენები გაუქმებულია (tokens.json-ში ink-ის რამპის ტოლია) — ფერადი ბლოკები აღარ არსებობს: გაკვეთილის ბარათი, PT კრედიტი, პროდუქტის მინიატურა ყველა ერთი ზედაპირია (მუქზე ink-900 + ink-800 ჩარჩო, ღიაზე თეთრი + ink-200), მეორეული ქმედება თეთრი ან ink-950 პილია. კლასის ტიპებს ტონის საფეხური ასხვავებს (#DCDCDA…#6C6C68). სტატუსი: ACTIVE/ATTENDED ლაიმი, WAITLIST/FROZEN ink, პრობლემა danger-წითელი — ერთადერთი ფუნქციური გამონაკლისი; warning, success, info, flame აღარ გამოიყენება.

## გარე გვერდები: შესვლა და checkout

პორტალის გარეთა გვერდები (web-member-login.tsx, web-checkout.tsx) ერთსა და იმავე ლოგიკას იყენებს: ტილო ink-950, ნავიგაცია არ არის (მხოლოდ ლოგო, KA/EN და ერთი ჯვარედინი ბმული), და ერთადერთი ლაიმის ველი ატარებს „ღირებულებას" — login-ზე შემდეგი გაკვეთილის ბლოკი გიგანტური მონო დროით, checkout-ზე შეკვეთის ბლოკი ჯამით და ink-950 ღილაკით. პატარა ჩექბოქსი/რადიო არასდროს არის ჩარჩოიანი (მოჭრილი კუთხე ჭრის ბორდერს და იშლება) — ჩართული ლაიმი, გამორთული ink-800 სავსე ოქტაგონია. გრიდის სვეტებს აუცილებლად min-w-0 სჭირდება, თორემ 390-ზე გვერდი გადის კიდეზე.
